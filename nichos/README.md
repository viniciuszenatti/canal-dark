# Nichos — base de conhecimento

Esta pasta guarda a **base por nicho** que alimenta os agentes (Trend Scout, Roteirista, Guardrail) e serve de guia pra revisão humana. Projeto pessoal do Vinicius — ver [[Canal Dark — MOC]].

## Como está organizado

- **[[00-tecnicas-shorts-comum]]** — técnicas de engajamento em Shorts que valem pra **todos** os nichos (gancho, retenção, ritmo, legenda, CTA). Os docs de cada nicho **referenciam** este, em vez de repetir.
- Dentro de cada nicho, 3 documentos:
  1. `01-conteudo-e-pesquisa.md` — que conteúdo o nicho apresenta + **como o bot deve pesquisar** (fontes, termos, o que buscar/evitar).
  2. `02-roteiro-e-linguagem.md` — **tom de voz e técnicas de escrita** específicas do nicho + exemplos de gancho (em inglês).
  3. `03-riscos-e-conformidade.md` — copyright, monetização e sensibilidade **específicos** do nicho.

## Nichos
- `true-crimes/` — casos reais, mistérios, crimes não resolvidos.
- `conspiracy-theories/` — mistérios/teorias de entretenimento (versão **segura**, sem desinformação).
- `one-piece-theories-and-stories/` — lore e teorias de One Piece.

> [!warning] Honestidade (regra 1)
> Estes docs são uma **base inicial** escrita do meu conhecimento — **não** de pesquisa web ao vivo de 2026. Política de plataforma e "o que está bombando" mudam rápido. Antes de produzir, o **Trend Scout** deve confirmar tendência atual, e vale uma rodada de pesquisa pra validar os pontos de risco. Use como ponto de partida forte, não como verdade fixa.

> [!note] Idioma
> Docs em português (pra você). **Exemplos de gancho/roteiro em inglês**, porque o canal é EN/global — já servem de few-shot pro agente Roteirista.
